# Comparaison Recharts / Chart.js

Recharts : composants React déclaratifs (<BarChart>, <Bar>...), rendu en SVG, très simple à intégrer dans React, personnalisation par composants.
Chart.js (react-chartjs-2) : rendu en canvas, configuration par objet (data + options), il faut enregistrer les éléments utilisés (register), plus performant avec beaucoup de points.

Ma conclusion : (à écrire : lequel j'ai trouvé plus simple, lequel est plus léger, lequel je choisirais pour un gros volume de données)
